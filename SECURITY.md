# Politique de sécurité — Ludarchive

## Signaler une faille

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité : elle serait visible par tous avant d'être corrigée.

Utiliser le signalement privé de GitHub : onglet **Security** du dépôt › **Report a vulnerability**, ou directement [ce lien](https://github.com/Emmelf/ludarchive/security/advisories/new).

Indiquer si possible :

- la partie concernée (page, fonctionnalité, endpoint de l'API) ;
- les étapes pour reproduire ;
- l'impact possible.

Le signalement n'est visible que par le mainteneur du dépôt. Un retour est donné dès que possible.

## Versions prises en charge

Seule la **dernière version publiée** (voir les [releases](https://github.com/Emmelf/ludarchive/releases)) reçoit des correctifs de sécurité.
